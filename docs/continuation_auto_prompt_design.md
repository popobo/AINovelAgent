# 自动生成续写提示词功能设计

## 功能概述

为续写页面添加自动生成提示词的功能，用户可以点击按钮让AI根据全局摘要自动生成续写提示词建议，而无需手动输入。

## 设计方案

### 1. API端点设计

**端点路径**: `POST /api/novels/[novelId]/continue/generate-prompt`

**功能**: 根据小说的全局摘要、最近章节摘要和元数据，生成3-5个续写提示词建议。

**请求参数**: 无（从路径获取novelId）

**响应格式**:
```json
{
  "prompts": [
    "提示词1",
    "提示词2",
    "提示词3"
  ]
}
```

**实现逻辑**:
1. 验证用户身份和权限
2. 获取小说的全局摘要（Summary.type = GLOBAL）
3. 获取最近3章的摘要
4. 获取小说元数据（人物、世界观等）
5. 组装上下文信息
6. 调用AI模型生成3-5个续写提示词
7. 返回JSON数组格式的提示词列表

### 2. 前端页面修改

**文件**: `app/novels/[novelId]/continue/page.tsx`

**新增功能**:
1. 添加"自动生成提示词"按钮
2. 添加加载状态显示
3. 显示生成的提示词列表
4. 点击提示词可自动填入输入框
5. 添加默认提示词作为后备方案

### 3. 默认提示词

当自动生成失败或用户不想使用AI生成时，提供以下默认提示词：

```typescript

  "展开新的情节线索，引入新的角色或事件",
```

## 实现步骤

创建文件: `app/api/novels/[novelId]/continue/generate-prompt/route.ts`

修改文件: `app/novels/[novelId]/continue/page.tsx`

### 步骤3: 添加默认提示词

## 错误处理

1. **API Key未配置**: 提示用户先配置OpenRouter API Key
2. **摘要数据缺失**: 提示用户先生成摘要
3. **AI生成失败**: 显示默认提示词
4. **网络错误**: 显示错误提示并提供重试按钮

## 用户体验优化

1. **加载状态**: 显示"生成中..."或加载动画
2. **一键填充**: 点击提示词直接填入输入框
3. **刷新按钮**: 允许用户重新生成不同的提示词
4. **默认提示**: 首次加载时显示默认提示词

## 数据依赖

生成提示词需要以下数据：
- 全局摘要（Summary.type = GLOBAL）
- 最近章节摘要（Summary.type = CHAPTER）
- 小说元数据（NovelMetadata）

如果数据缺失，API应返回默认提示词。
